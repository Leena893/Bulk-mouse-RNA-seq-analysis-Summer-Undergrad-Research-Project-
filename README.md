# Bulk-mouse-RNA-seq-analysis-Summer-Undergrad-Research-Project-
Code is based on publicly avaliable data and pipelines from Xiao et al. Four scripts included: 1) analysis using GOBP &amp; Hallmark, 2) analysis using KEGG, 3) analysis using Reactome, 4) analysis using all three background genesets (Tirthankar's code).
